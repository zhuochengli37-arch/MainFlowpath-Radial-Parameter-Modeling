# 依赖与模型速查

## 1. 文档定位

这是一份速查表，只保留最常用信息：

- 运行要装哪些依赖；
- 常见模型大类有哪些；
- 真实模型注册应该看哪里；
- 离线部署时优先核对什么。

## 2. 核心运行依赖

| 依赖 | 主要用途 |
|---|---|
| `numpy` | 数值计算 |
| `scipy` | 插值与数值方法 |
| `scikit-learn` | 大部分回归模型与预处理 |
| `xgboost` | XGBoost 模型 |
| `lightgbm` | LightGBM 模型 |
| `PyYAML` | 读取 YAML 配置 |
| `joblib` | 模型保存与加载 |
| `tqdm` | 进度显示 |

开发与测试常见附加依赖：

- `pytest`
- `python-dotenv`

## 3. 模型注册以哪里为准

当前正式模型注册以这里为准：

- `workbase/src/project1/modeling/factory.py`

如果历史文档、旧配置注释和这里不一致，应以后者为准。

## 4. 最常见模型家族

| 类别 | 常见模型 |
|---|---|
| 基础基线 | `linear_deg2`、`ridge_deg2` |
| 平滑拟合 | `spline_regression`、`gpr_rbf`、`gpr_matern` |
| 邻域/插值 | `knn_distance`、`rbf`、`lowess_like` |
| 树模型 | `random_forest`、`gradient_boosting`、`xgboost`、`lightgbm` |
| 正则化 | `lasso`、`elastic_net` |
| 核方法 | `svr_rbf` |
| 结构模型 | `piecewise_ridge`、`tensor_spline`、`hierarchical_workline`、`endpoint_hub_tip`、`physics_clamped_ridge` |

## 5. 不同场景下常见关注点

| 场景 | 常见关注点 |
|---|---|
| 1D | 是否要补 `wcor`，是否启用 GPR |
| 2D | 分区后样本量是否足够 |
| 3D | 分区、split mode、模型筛选指标 |
| generic | 表头、输入列数量、输出列一致性 |

## 6. 离线部署时建议优先核对

1. Python 版本是否匹配。
2. `numpy / scipy / scikit-learn / xgboost / lightgbm / PyYAML / tqdm` 是否齐全。
3. `python -m project1 --help` 是否正常。
4. 模型目录中的 `.pkl` 与元数据文件是否成对存在。

## 7. 遇到问题先看哪里

- 用法问题：`docs/程序使用手册.md`
- 配置问题：`docs/基准配置指南.md`
- 预测链路问题：`docs/已训练模型预测指南.md`、`docs/方法二与方法三预测指南.md`
- 版本兼容问题：`docs/模型版本管理指南.md`
