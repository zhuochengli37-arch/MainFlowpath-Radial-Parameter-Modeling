# 模型说明

## 1. 这份文档讲什么

本文只回答三个问题：

1. 项目里大致有哪些模型类型；
2. 它们通常出现在哪些工作流里；
3. 实际看代码时，应该以哪里为准。

如果你想看：

- 如何挑模型：看 `docs/模型分类说明.md`
- 如何看指标：看 `docs/模型评估指南.md`
- 当前保存了哪些依赖与模型名：看 `docs/依赖与模型速查.md`

## 2. 实际以哪里为准

当前程序真正使用的模型注册，以这里为准：

- `workbase/src/project1/modeling/factory.py`

文档、历史配置注释、旧报告里可能出现过别的模型名，但是否真正参与当前运行，最终都应以后端模型工厂为准。

## 3. 项目里的模型大类

当前项目常见模型可以粗分为下面几类：

- 多项式与基础线性模型：适合做稳定基线。
- 样条与平滑拟合模型：适合连续变化明显的数据。
- 邻域与插值模型：适合局部插值型任务。
- 树模型与集成模型：适合复杂非线性关系。
- 正则化线性模型：适合控制复杂度或做稀疏化。
- 支持向量回归：适合中小样本非线性场景。
- 高斯过程回归：适合平滑拟合与不确定性较敏感的场景。
- 领域特定结构模型：适合当前项目的结构化气动数据。

## 4. 不同工作流里通常会遇到什么

### 4.1 1D

常见输入形式：

- `rpm -> wcor`
- `xi -> psi/tsi/mai`

特点：

- 候选模型相对简单；
- 常用于先做基线、补 `wcor` 或快速验证单输入关系；
- 方法二、方法三里都会用到 1D 模型。

### 4.2 2D

常见输入形式：

- `(rpm, xi) -> outputs`

特点：

- 常用于方法二；
- 对每个分区的样本量更敏感；
- 如果分区样本太少，2D 模型可能无法稳定训练。

### 4.3 3D

常见输入形式：

- `(rpm, wcor, xi) -> outputs`

特点：

- 是当前结构化气动数据的主建模场景；
- 会结合分区、split mode、排行榜与目标列独立选模；
- 领域特定模型主要集中在这里。

### 4.4 generic 通用表格

特点：

- 面向“前 N 列输入、其余列输出”的通用表格；
- 不依赖结构化目录元数据；
- 适合新数据集快速试模。

## 5. 当前最常见的模型家族

你在报告、排行榜和代码里最常看到的大致会是这些：

- 基础基线：`linear_deg2`、`ridge_deg2`
- 平滑拟合：`spline_regression`、`gpr_rbf`、`gpr_matern`
- 邻域/插值：`knn_distance`、`rbf`、`lowess_like`
- 树模型：`random_forest`、`gradient_boosting`、`xgboost`、`lightgbm`
- 正则化：`lasso`、`elastic_net`
- 核方法：`svr_rbf`
- 3D 结构模型：`piecewise_ridge`、`tensor_spline`、`hierarchical_workline`、`endpoint_hub_tip`、`physics_clamped_ridge`

## 6. 使用时最重要的判断顺序

如果你想判断“这次到底用了什么模型”，建议按这个顺序看：

1. 先看 `project1.modeling.factory` 里是否注册。
2. 再看当前工作流是 1D、2D、3D 还是 generic。
3. 再看配置里是否启用了如 `include_gpr` 这类开关。
4. 最后看实际输出目录中的排行榜与模型清单。
