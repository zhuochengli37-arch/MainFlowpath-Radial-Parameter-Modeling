# 项目报告

## 1. 项目概述

`AIR2 Project1` 是一个面向气动性能预测任务的离线机器学习项目，支持：

- 1D / 2D / 3D benchmark；
- 训练后模型保存；
- 基于已保存模型的批量预测；
- 结构化 Markdown 报告输出；
- 离线部署与回归验证。

## 2. 当前架构状态

截至当前版本，项目已经完成以下关键演进：

1. 共享能力已从大脚本拆出；
2. benchmark 主流程已拆分为数据、分区、报告和运行编排模块；
3. 模型定义与模型工厂已统一收口到 `workbase/src/project1/modeling`；
4. 统一入口 `project1` 已落地，成为当前推荐入口；
5. 旧脚本入口继续保留兼容。

## 3. 当前推荐入口

### 3.1 领域专用工作流

- `python -m project1 current benchmark-1d`
- `python -m project1 current predict-1d`
- `python -m project1 current benchmark-2d`
- `python -m project1 current predict-2d`
- `python -m project1 current benchmark-3d`
- `python -m project1 current predict-3d`
- `python workbase/current_scripts/workline_pipeline.py`

### 3.2 通用工作流

- `python -m project1 generic benchmark-1d`
- `python -m project1 generic predict-1d`
- `python -m project1 generic benchmark-2d`
- `python -m project1 generic predict-2d`
- `python -m project1 generic benchmark-3d`
- `python -m project1 generic predict-3d`

## 4. 兼容入口

以下脚本仍然保留兼容：

- `workbase/current_scripts/*.py`
- `workbase/generic_scripts/*.py`

它们当前主要用于：

- 历史流程衔接；
- 回归测试；
- 对照排查。

## 5. 架构分层

### 5.1 入口层

- `project1` 包级统一入口；
- `current_scripts` / `generic_scripts` 兼容脚本入口。

### 5.2 核心逻辑层

当前核心逻辑主要位于：

- `workbase/src/project1/experiments/`
- `workbase/src/project1/modeling/`

### 5.3 共享支撑层

主要位于：

- `workbase/common/`

这层负责配置加载、日志、校验、通用表格处理、模型版本管理等公共能力。

### 5.4 服务层

数据读取、元数据解析和辅助服务位于：

- `workbase/src/project1/services/`

## 6. 支持的数据案例

- `DATACASE1`：领域专用结构化 3D 数据，也常作为方法二/方法三的数据来源；
- `sample6`：当前项目 1D 数据；
- `DATACASE3`：通用 2D 表格数据；
- `DATACASE4`：通用 3D 表格数据；
- `DATACASEVAR_*`：结构化变体数据集，用于 benchmark 与报告验证。

## 7. 当前输出形态

训练与预测通常会产出：

- 已保存模型；
- 元数据文件；
- 排行榜；
- Markdown 报告；
- 配置快照；
- 结构化预测结果；
- 预测清单文件。

## 8. 当前技术特点

### 8.1 模型评估输出已统一

当前 3D 报告会：

1. 使用真实样本数；
2. 先列出按 `RMSE` 的整体最佳模型；
3. 再列出按 `MAPE` 的整体最佳模型；
4. 然后分别按 `RMSE` 和 `MAPE` 完整排序输出其余模型。

### 8.2 预测输出更可复现

- 模型元数据会随模型一起保存；
- 训练配置快照会自动保留；
- 通用预测结果会优先保留原始列并追加 `pred_*` 列。

### 8.3 统一入口体验已收敛

- `current ... --help` 可直接显示帮助；
- `generic ... --help` 也已改为统一入口本地解析；
- 帮助查看不会再先触发底层脚本日志初始化。

## 9. 当前结论

项目当前已经形成“统一入口 + 兼容入口 + 回归测试 + 中文文档”的完整交付状态。  
如果以稳定使用为目标，建议优先走：

- `python -m project1 current ...`
- `python -m project1 generic ...`

如果需要兼容旧流程，再回退到脚本入口即可。
