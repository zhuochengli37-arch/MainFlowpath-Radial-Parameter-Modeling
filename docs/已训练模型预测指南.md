# 已训练模型预测指南

## 1. 文档目标

本文说明在已经有训练结果的前提下，如何直接执行预测。这里重点覆盖两类常见场景：

- 1D：`rpm -> wcor`
- 3D：`(rpm, wcor, xi) -> outputs`

如果预测阶段缺少真实 `wcor`，请优先阅读：

- `docs/方法二与方法三预测指南.md`

那份文档专门说明：

- 方法二：`1D + 2D`
- 方法三：`1D + 3D`

## 2. 基本原则

当前项目建议通过 `config/benchmark_config.yaml` 统一控制预测流程，包括：

- 预测输入目录
- 已训练模型目录
- 预测结果输出目录
- 3D 预测时的模型选择指标

不建议在脚本内部手动修改路径常量。这样可以保留配置快照，也更容易复现实验。

## 3. 1D 已训练模型预测

### 3.1 典型配置

```yaml
predict_1d:
  paths:
    input: "./data/current/3d/CASE2-3/predict"
    model_output: "./data/current/3d/CASE2-2/output_1d"
    output: "./data/current/3d/CASE2-3/results_1d"
```

含义如下：

- `input`：待预测输入目录
- `model_output`：已经训练好的 1D 模型目录
- `output`：1D 预测结果目录

### 3.2 执行命令

```powershell
python -m project1 current predict-1d
```

### 3.3 输出说明

`predict-1d` 会从预测文件路径中解析部件和级号，并根据训练输出中的 `leaderboard.json`，在对应分区内选择目标列的最佳模型。流量模型按如下目录保存：

```text
models/<部件_级号>/<模型名称>_wcor.pkl
```

例如，`DATABASE_HTB/STAGE_1` 对应 `models/HTB_S1/`。预测结果写入：

```text
predict_1d.paths.output
```

如果原始输入只有 `rpm` 或 `rpm xi`，输出文件会保留原始列，并追加预测列。例如：

```text
rpm xi wcor
...
```

## 4. 3D 已训练模型预测

### 4.1 典型配置

```yaml
predict_3d:
  paths:
    input: "./data/current/3d/CASE2-3/results_1d"
    model_output: "./data/current/3d/CASE1/output"
    output: "./data/current/3d/CASE2-3/results_3d"
```

含义如下：

- `input`：包含 `rpm / wcor / xi` 的预测输入目录
- `model_output`：已经训练好的 3D 模型目录
- `output`：3D 预测结果目录

### 4.2 执行命令

```powershell
python -m project1 current predict-3d
```

### 4.3 输入要求

3D 预测需要完整三元输入：

- `rpm`
- `wcor`
- `xi`

这些字段可以来自文件列，也可以来自结构化路径和文件名。只要程序能够识别这三项，就可以组装成 3D 模型需要的输入。

## 5. 常见组合

### 5.1 只用已训练 1D 模型补流量

```powershell
python -m project1 current predict-1d
```

适用于：

- 只想先得到 `wcor`
- 暂时不继续做 3D 预测

### 5.2 连续执行方法三

```powershell
python -m project1 current predict-1d
python -m project1 current predict-3d
```

适用于：

- 原始输入只有 `rpm + xi`
- 需要先补 `wcor`
- 需要再把补齐后的结果送入已有 3D 模型

此链路的数据组织规则请见：

- `docs/方法二与方法三预测指南.md`

## 6. 预测前检查

建议至少确认以下事项：

1. `model_output` 目录下存在训练好的模型文件和元数据文件。
2. `input` 目录结构与当前预测脚本可识别的格式一致。
3. `output` 目录不要与训练输出目录混用，避免覆盖模型或报告。
4. 如果执行方法三，输入文件名不要继续使用数值型 `wcor` 文件名。
5. 如果 3D 预测需要指定模型选择方式，检查 `selection_split_mode` 和 `selection_metric`。
