# AIR2 Project1 验证算例与结果说明

## 1. 文档定位

本文用于说明当前程序在 `CASE1 / CASE2` 数据上的验证情况。报告重点不是给出总体平均误差，而是按算例和分区说明程序在不同应用场景下的交叉验证结果与预测链路可用性。

本报告包含四个算例：

| 算例 | 验证目的 | 方法含义 |
|---|---|---|
| `CASE1` | 完整 3D 建模验证 | 已知 `(rpm, wcor, xi)`，训练 3D 径向分布代理模型 |
| `CASE2-1` | 流量已知 3D 预测验证 | 已知 `(rpm, wcor, xi)`，验证流量已知条件下的 3D 建模与预测链路 |
| `CASE2-2` | 方法二验证 | `1D: rpm -> wcor`，再用 `2D: rpm, xi -> y` |
| `CASE2-3` | 方法三验证 | `1D: rpm -> wcor`，再用 `3D: rpm, wcor, xi -> y` |

为保持四个算例的报告格式一致，后文每个算例均按以下顺序组织：

1. 算例说明。
2. 运行配置。
3. 分区交叉验证结果。
4. 输出验证。
5. 结果说明。

其中，分区交叉验证结果均按分区列出，不再使用总体聚合结果作为主要结论。表中每个目标量列出该分区下按 RMSE 排序得到的最佳模型。

## 2. 数据与指标说明

### 2.1 数据规模

| 算例 | 训练文件数 | 训练径向样本行数 | 预测文件数 | 说明 |
|---|---:|---:|---:|---|
| `CASE1` | 42 | 1140 | - | 完整 3D 建模数据 |
| `CASE2-1` | 7 | 190 | 7 | 流量已知，直接 3D 预测 |
| `CASE2-2` | 7 | 190 | 7 | 方法二验证，生成 2D 预测和合并结果 |
| `CASE2-3` | - | - | 7 | 方法三验证，生成 1D 中间结果和 3D 最终结果 |

其中，`CASE2-1` 与 `CASE2-2` 的训练数据完全一致，均为人为构造的“一转速对应一个流量点”稀疏数据；`CASE2-3` 使用同一组稀疏预测输入，并通过 1D 模型先补全 `wcor`。因此，`CASE2` 组内的 3D 模型复用应以 `CASE2-1/output` 为准，而不应直接复用 `CASE1` 完整数据库模型作为 `CASE2` 算例的测试结果。

`CASE1` 包含两个主要分区：

| 分区 | 文件数 | 径向样本行数 | 说明 |
|---|---:|---:|---|
| `CMP:S1` | 18 | 900 | `CMP` 对应模拟 `STAGE 35` |
| `HTB:S1` | 24 | 240 | `HTB` 对应模拟 `KG66` |

需要说明的是，`CMP` 数据当前尚未完全统一无量纲化，因此 `psi` 的绝对误差需要结合数据背景解释。对 `psi` 这类数值尺度较大的变量，报告中应优先结合相对误差判断模型效果。

### 2.2 误差指标

| 指标 | 含义 | 用途 |
|---|---|---|
| RMSE | 均方根误差 | 对局部大误差较敏感，用于模型排序 |
| MAE | 平均绝对误差 | 反映平均预测偏差 |
| 相对误差 | 误差相对于目标量尺度的比例 | 用于跨目标量比较 |
| R2 | 决定系数 | 反映模型对样本变化趋势的解释能力 |

本文中的“相对误差”按 MAPE 的百分数形式给出。

## 3. CASE1：完整 3D 建模验证

### 3.1 算例说明

`CASE1` 用于验证程序在完整径向分布数据库上的三维建模能力。该算例中，每个工况文件包含若干径向位置上的 `mai / psi / tsi`，程序将目录中的工况信息与文件内径向位置合并，构造三输入回归样本。

输入变量为：

```text
rpm, wcor, xi
```

输出变量为：

```text
mai, psi, tsi
```

因此，该算例对应技术报告中的三输入代理模型问题：

```text
f: (n, w, xi) -> y
```

其中，`rpm` 对应转速 `n`，`wcor` 对应换算流量 `w`，`xi` 对应相对径向位置。

### 3.2 运行配置

`CASE1` 采用完整 3D benchmark 配置，具体如下。

|---|---|
| 训练输入目录 | `data/current/3d/CASE1/train` |
| benchmark 输出目录 | `data/current/3d/CASE1/output` |
| 输入变量 | `rpm, wcor, xi` |
| 输出变量 | `mai, psi, tsi` |
| `radial_mode` | `full` |
| `partition_mode` | `multi` |
| 分区键 | `component, stage` |
| 交叉验证折数 | `3` |
| `max_samples` | `10000` |
| `include_gpr` | `true` |
| 主要模型选择指标 | `RMSE` |

### 3.3 分区交叉验证结果

`CASE1` 采用 `multi` 分区模式，按部件和级数形成 `CMP:S1` 与 `HTB:S1` 两个分区。下表列出 `random` 交叉验证划分下，各分区、各目标量的最佳模型结果。

| `HTB:S1` | `random` | `mai` | `gpr_matern` | 3 | 240 | 0.035448 | 0.013071 | 1.035% | 0.9705 |


### 3.5 结果说明

`CASE1` 的分区交叉验证结果表明，完整 3D 数据条件下，程序能够在 `CMP:S1` 和 `HTB:S1` 两个分区内分别完成模型训练、交叉验证和模型选择。两个分区中三个目标量的最佳模型均为 `gpr_matern`，说明 Matérn 核高斯过程回归适合当前小样本、连续径向分布的建模任务。

从分区结果看，`CMP:S1` 的样本量较大，三个目标量均取得较高 R2；`HTB:S1` 的样本量较少，但整体误差仍保持在可接受范围内。该算例主要用于说明完整数据库条件下的 3D 建模能力，并作为与 `CASE2` 稀疏数据算例对照的基准。

## 7. 方法对比

四个算例的关系如下。

| 算例 | 是否训练最终预测模型 | 是否已知真实 `wcor` | 最终预测模型 | 主要作用 |
|---|---|---|---|---|
| `CASE1` | 是 | 是 | 3D 分区模型 | 建立完整数据库 3D 建模能力 |
| `CASE2-1` | 是 | 是 | 3D 分区模型 | 验证流量已知时的 3D 建模与预测链路 |
| `CASE2-2` | 是 | 否 | 2D 分区模型 | 验证 `1D + 2D` 简化路径 |
| `CASE2-3` | 否，复用 `CASE2-1` 3D 模型 | 否 | 3D 分区模型 | 验证 `1D + 3D` 工程应用路径 |

从当前结果看，`CASE1` 说明程序具备完整数据库 3D 建模能力；`CASE2-1` 说明同一稀疏数据条件下可以训练并调用 3D 分区模型；`CASE2-2` 说明二维简化方法可执行，但受稀疏分区样本量限制；`CASE2-3` 说明通过补全 `wcor` 并复用 `CASE2-1` 的 3D 模型，可以形成更适合当前稀疏数据条件的工程应用链路。
