# 文档索引

## 1. 建议先读

如果刚接手这个项目，建议按下面顺序阅读：

1. `docs/程序使用手册.md`
2. `docs/基准配置指南.md`
3. `docs/方法二与方法三预测指南.md`
4. `docs/程序测试报告.md`

## 2. 核心文档

- `docs/程序使用手册.md`：项目主手册，覆盖统一入口、目录结构、数据组织、训练预测流程和常见问题。
- `docs/程序测试报告.md`：记录最近一轮程序测试、回归验证与结论。
- `docs/基准配置指南.md`：说明 `config/benchmark_config.yaml` 的主要字段和使用方式。
- `docs/迁移指南.md`：说明从历史脚本入口迁移到当前统一入口的方法。
- `docs/研究所数据Schema说明.md`：区分Legacy、研究所单截面和四截面Schema，并说明当前训练边界。
- `docs/研究所四截面数据Adapter说明.md`：记录正式四截面真实表头、宽表拆分规则、canonical结构和模型准入边界。
- `docs/研究所多截面数据框架说明.md`：说明动态section、outputs、alias、Schema版本和参数来源追踪设计。
- `docs/研究所多截面模型训练说明.md`：说明Multi-Section的1D/2D/3D训练准入、分区、动态targets和模型元数据边界。

## 3. 预测相关文档

- `docs/已训练模型预测指南.md`：已经有 1D / 3D 模型时，如何直接执行预测。
- `docs/方法二与方法三预测指南.md`：预测阶段缺少真实 `wcor` 时，如何使用方法二 `1D + 2D` 或方法三 `1D + 3D`。
- `docs/模型版本管理指南.md`：说明模型元数据、配置快照和依赖兼容性检查。

原来的旧版 workline 预测说明已经移除，相关内容已合并到 `docs/方法二与方法三预测指南.md`，避免同一流程分散在多份文档中。

## 4. 模型理解与评估

- `docs/模型说明.md`：说明项目内主要模型类型与适用场景。
- `docs/模型分类说明.md`：说明模型分类、比较方式与使用建议。
- `docs/模型评估指南.md`：说明常见评估指标、对比方法与结果解释建议。
- `docs/依赖与模型速查.md`：快速索引依赖、模型和相关文档。

## 8. 当前正式入口

当前推荐优先使用统一入口：

```powershell
python -m project1 current benchmark-1d
python -m project1 current predict-1d
python -m project1 current benchmark-2d
python -m project1 current predict-2d
python -m project1 current benchmark-3d
python -m project1 current predict-3d
python -m project1 generic benchmark-1d
python -m project1 generic predict-1d
python -m project1 generic benchmark-2d
python -m project1 generic predict-2d
python -m project1 generic benchmark-3d
python -m project1 generic predict-3d
```

`workbase/current_scripts/workline_pipeline.py` 仍然是方法二的一键串联入口，适合连续执行：

```text
benchmark-1d -> benchmark-2d -> predict-1d -> predict-2d
```
