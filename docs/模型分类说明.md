# 模型分类说明

## 1. 文档目的

本文不重复列完整模型清单，而是帮助你快速判断：

- 这类模型大概适合什么场景；
- 为什么某一类模型会在某些数据上表现更好；
- 做工程选择时应该优先看什么。

## 2. 基础可解释模型

典型代表：

- `linear_deg2`
- `ridge_deg2`
- `poly2`
- `poly3`

适合场景：

- 先做基线；
- 样本量不大；
- 希望结果稳定、便于解释。

优点：

- 快；
- 稳；
- 便于做对照。

局限：

- 对复杂非线性关系表达能力有限。

## 3. 平滑拟合模型

典型代表：

- `spline_regression`
- `tensor_spline`
- `gpr_rbf`
- `gpr_matern`

适合场景：

- 曲线或曲面比较平滑；
- 更关心连续趋势而不是极端局部波动；
- 需要更细腻的拟合结果。

局限：

- 训练和调参成本通常高于基础模型。

## 4. 邻域与插值模型

典型代表：

- `knn_distance`
- `rbf`
- `lowess_like`

适合场景：

- 样本在局部空间分布较密；
- 主要做插值，不强调远距离外推；
- 更重视邻近样本的局部趋势。

局限：

- 外推能力通常一般；
- 对样本覆盖范围比较敏感。

## 5. 树模型与集成模型

典型代表：

- `random_forest`
- `gradient_boosting`
- `xgboost`
- `lightgbm`

适合场景：

- 关系复杂、非线性较强；
- 需要较强拟合能力；
- 不想做太多人工特征工程。

优点：

- 在很多工程问题上容易得到较强表现。

局限：

- 可解释性通常弱于线性或样条类模型。

## 6. 正则化线性模型

典型代表：

- `lasso`
- `elastic_net`

适合场景：

- 特征较多；
- 希望控制复杂度；
- 希望抑制过拟合。

## 7. 核方法

典型代表：

- `svr_rbf`

适合场景：

- 中小样本；
- 明显非线性；
- 愿意接受较高训练成本换拟合能力。

## 8. 领域特定结构模型

典型代表：

- `piecewise_ridge`
- `hierarchical_workline`
- `endpoint_hub_tip`
- `physics_clamped_ridge`

适合场景：

- 当前项目的结构化气动数据；
- 需要利用分段、工作线、物理约束等先验；
- 希望模型更贴近工程结构。

## 9. 选模型时怎么想更实用

建议按下面顺序判断：

1. 先看任务是 1D、2D、3D 还是 generic。
2. 再看样本量是否足够，尤其是 2D/3D 分区后的样本量。
3. 再看你更重视稳定基线、局部插值、还是复杂非线性拟合。
4. 最后结合排行榜，用 `RMSE`、`MAPE` 和分区表现一起判断。

## 10. 一句式建议

- 想先稳稳起步：先看 `ridge_deg2`
- 想冲性能：先看 `xgboost`、`lightgbm`
- 想看平滑趋势：先看 `spline_regression`、`gpr_matern`
- 想做局部插值：先看 `knn_distance`、`rbf`
- 想利用结构先验：先看 `hierarchical_workline`、`physics_clamped_ridge`
